# Comic Book Maker

A Progressive Web Application (PWA) for creating, editing, and sharing digital comic books.

## Environments

- **Local:** run `npm run dev` (normally `http://localhost:5173`).
- **Staging:** [comic-book-maker.netlify.app](https://comic-book-maker.netlify.app/).
- **Live production:** none yet; this is currently a personal project.

Netlify hosts the frontend; Supabase provides authentication and backend services. See [environment details](docs/environments.md) for the verified project identifiers and [Civitai setup](docs/civitai-setup.md) for the pending image-model rollout.

## Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
