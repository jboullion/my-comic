# Story AI

Get AI-powered help with dialogue, plot ideas, and scene descriptions. The Story AI assistant can analyze your current page and provide contextual suggestions.

## Getting Started

1. Open the **Story AI** panel in the right sidebar
2. Select an AI model from the dropdown
3. Type your question or request
4. Press Enter or click Send

## Features

### Vision Support

Many models can analyze images to provide better suggestions:

| Action | Description |
|--------|-------------|
| Capture Page | Takes a screenshot of your current canvas |
| Upload Image | Attach any image file for analysis |

When an image is attached, the AI can:
- Describe what's happening in the scene
- Suggest dialogue based on character positions
- Recommend improvements to composition
- Help write narration that matches the visuals

### Project Context

The AI automatically knows about your project:
- Project title and current page number
- Characters in your series with their descriptions
- Custom story prompts (if configured)

This context helps the AI give more relevant suggestions.

### Chat History

Your conversation is saved per project (up to 50 messages). Clear history using the button in the panel header.

## Custom Story Prompts

You can set a custom story prompt for any project to give the AI specific instructions about your story:

1. Click the **Edit Prompt** button (pencil icon) in the Story AI panel header
2. This opens **Project Settings > AI** tab
3. Write instructions about your story's tone, setting, or rules
4. Click **Save** to apply the changes

The AI will follow your custom guidelines in all responses. If no custom prompt is set, a sensible default is used.

Example custom prompt:
```
This is a noir detective comic set in 1940s Chicago.
The dialogue should be snappy and use period-appropriate slang.
The main character, Detective Blake, is cynical but has a hidden heart of gold.
```

## Example Prompts

**For Dialogue:**
- "Write dialogue for this confrontation scene"
- "How would [character name] react to this situation?"
- "Make this dialogue more dramatic"

**For Story:**
- "What should happen next in this scene?"
- "I'm stuck on the plot, here's what happened so far..."
- "Suggest a twist for this story"

**For Descriptions:**
- "Write a caption for this panel"
- "Describe this scene for narration"
- "What sound effects would fit here?"

## Tips

- Capture the page before asking about specific scenes
- Reference character names - the AI knows who they are
- Be specific about what you need (dialogue, description, ideas)
- Use custom prompts for consistent tone across your project
- Different models have different strengths - experiment!
