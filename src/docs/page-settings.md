# Page Settings

Each page can have its own settings that override project defaults.

## Accessing Page Settings

1. Select a page from the left sidebar
2. Open the **Page** tab in the right sidebar

## Page Dimensions

### Size

| Setting | Description |
|---------|-------------|
| Width | Page width in pixels |
| Height | Page height in pixels |

### Presets

Quickly apply common comic dimensions:

| Preset | Dimensions |
|--------|------------|
| Standard Comic | 800 x 1200 px |
| Manga | 600 x 900 px |
| Square | 1000 x 1000 px |

## Background

| Setting | Description |
|---------|-------------|
| Background Color | Page background color |
| Transparent | Enable transparent background (for export) |

## Grid and Rulers

### Show Rulers

Display measurement rulers along the top and left edges of the canvas. Rulers help with precise element placement.

### Show Grid

Display a grid overlay on the canvas. The grid helps align elements visually.

### Snap to Grid

When enabled, elements snap to grid intersections when moved or resized. This ensures precise alignment.

### Grid Size

Adjust the grid spacing in pixels:

- **Default:** 20px
- **Smaller grids** (10px) for fine control
- **Larger grids** (50px) for quick layouts

## Page Navigation

### Thumbnails

The left sidebar shows thumbnails of all pages. Click a thumbnail to switch to that page.

### Adding Pages

Click the **+** button at the bottom of the page list to add a new page. New pages inherit your project's default settings.

### Deleting Pages

Select a page and use the delete option to remove it. Projects must have at least one page.

## Tips

- Use consistent page dimensions throughout your comic
- Enable "Snap to Grid" for clean, aligned layouts
- Set background to transparent if you plan to overlay on other content
- Use rulers to maintain consistent margins
