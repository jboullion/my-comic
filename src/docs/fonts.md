# Fonts

Comic Book Maker includes a variety of fonts for creating authentic comic book text, plus the ability to add custom Google Fonts to your projects.

## Default Fonts

The following fonts are always available in your projects:

## Custom Fonts

You can add additional Google Fonts to any project for more variety.

### Adding Custom Fonts

1. Go to **Project Settings** (gear icon in the editor)
2. Click the **Fonts** tab
3. Type the exact font name from [Google Fonts](https://fonts.google.com)
4. Click **Add Font**

The font will be validated against Google Fonts and added to your project if found.

### Using Custom Fonts

Once added, custom fonts appear in the font dropdown when editing:

- Text elements
- Speech bubbles
- Text effects

Custom fonts are grouped under the "Custom" category in the font selector.

### Removing Custom Fonts

1. Go to **Project Settings > Fonts**
2. Find the font in the custom fonts list
3. Click the **X** button to remove it

## Font Usage Tips

### For Speech Bubbles

- **Comic Neue** works great for dialogue
- Keep font sizes readable (14-18px typical)
- Use consistent fonts for the same character

### For Text Effects (POW!, BAM!)

- **Bangers** is perfect for impact words
- Larger font sizes (48px+) work best
- Add stroke colors for extra punch

### For Captions & Narration

- **Caveat** or **Permanent Marker** for handwritten feel
- **Noto Sans** or **Roboto** for clean narration boxes
- Keep sizes smaller than dialogue (12-14px)

## Font Embedding in Exports

When you export your comic pages, all fonts (including custom fonts) are automatically embedded. This ensures your text renders correctly regardless of what fonts the viewer has installed.

**Note:** Very large fonts (over 5MB) may be skipped during export embedding to prevent performance issues. Most Google Fonts are well under this limit.

## Finding New Fonts

Visit [Google Fonts](https://fonts.google.com) to browse thousands of free fonts. Some recommendations for comics:

- **Manga style:** Hachi Maru Pop, Zen Maru Gothic
- **Handwritten:** Indie Flower, Shadows Into Light
- **Retro:** Press Start 2P, VT323
- **Decorative:** Creepster, Nosifer
