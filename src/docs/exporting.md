# Exporting

Export your comic pages as images or save project files for backup.

## Export All Pages

1. Click the **Export** button in the header
2. Choose a format
3. Click **Export**
4. A ZIP file downloads containing all pages as numbered images

## Export Formats

| Format | Best For |
|--------|----------|
| **WebP** | Best quality-to-size ratio (recommended) |
| **PNG** | Lossless quality, larger files |
| **JPEG** | Smallest files, slight quality loss |

### WebP (Recommended)
- Modern format with excellent compression
- Supports transparency
- Smallest file sizes with great quality
- Supported by all modern browsers

### PNG
- Lossless compression (no quality loss)
- Supports transparency
- Larger file sizes
- Best for archiving or further editing

### JPEG
- Lossy compression (slight quality reduction)
- Smallest file sizes
- No transparency support
- Best for web sharing where size matters

## Saving Projects

### Auto-Save
Your work is **automatically saved** as you make changes. You'll see a "Saving..." indicator that changes to "Saved" when complete.

### Manual Save
Press `Ctrl+S` (or `Cmd+S` on Mac) to manually save.

### Save as File
Click **Save As** to download a `.mycomic` file:
- Contains all project data
- Can be shared or backed up
- Open later with **Open Project**

## Opening Projects

### From Project List
Click any project card on the Projects page to open it.

### From File
Use **Open Project** to load a `.mycomic` file from your computer.

## Tips

- Export as **WebP** for web publishing
- Export as **PNG** for print or further editing
- Keep `.mycomic` backups of important projects
- All exports include all pages in the project
