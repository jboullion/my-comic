# Getting Started

Comic Book Maker is a browser-based application for creating digital comic books. All your work is saved locally in your browser - no account required.

## Requirements

- Modern web browser (Chrome, Firefox, Edge, Safari)
- No installation needed - runs entirely in your browser

## Quick Start

1. Go to the **Projects** page
2. Click **New Project** to create your first comic
3. Start adding images, speech bubbles, and text to your pages

## Key Features

- **Free & Local** - No account needed, all data stays on your device
- **Multiple Element Types** - Images, speech bubbles, text, and text effects
- **Professional Tools** - Zoom, pan, grid, rulers, and snap-to-grid
- **Export Options** - Save as WebP, PNG, or JPEG

## Interface Overview

The editor consists of:

- **Left Sidebar** - Page thumbnails for navigation
- **Canvas** - The main editing area
- **Right Sidebar** - Properties and assets panels
- **Toolbar** - Quick access to add elements and tools
- **Header** - Project name, save status, and main actions
