# Getting Started

Comic Book Maker is a browser-based application for creating digital comic books. All your work is saved locally in your browser.

## Requirements

- Modern web browser (Chrome, Firefox, Edge, Safari)
- No installation needed - runs entirely in your browser

## Quick Start

1. Go to the **Projects** page
2. Click **New Project** to create your first comic
3. Start adding images, speech bubbles, and text to your pages

## Key Features

- **Free & Local** - No account needed, all data stays on your device
- **Multiple Element Types** - Images, speech bubbles, text, and text effects
- **Professional Tools** - Zoom, pan, grid, rulers, and snap-to-grid
- **Export Options** - Save as WebP, PNG, or JPEG
- **AI-Powered** - Generate images and get story assistance with AI

## AI Features

Comic Book Maker includes AI tools to help with your creative process:

- **AI Image Generation** - Create comic images from text descriptions using FLUX models. Choose from different styles (Comic, Manga, Realistic, Retro) and use character references for consistency. Press **A** or click the AI Image button in the toolbar.

- **Story AI Assistant** - Get help with dialogue, plot ideas, and scene descriptions. The AI can analyze your current page and provide contextual suggestions. Access via the Story AI panel in the right sidebar.

See [AI Image Generation](/docs/ai-image-generation) and [Story AI](/docs/story-ai) for detailed guides.

## Interface Overview

The editor consists of:

- **Left Sidebar** - Page thumbnails for navigation
- **Canvas** - The main editing area
- **Right Sidebar** - Properties and assets panels
- **Toolbar** - Quick access to add elements and tools
- **Header** - Project name, save status, and main actions
