# Text Elements

Text elements are perfect for captions, narration, titles, and labels.

## Adding Text

1. Click the **Text** button (T) in the toolbar
2. A text box appears at the center of the canvas
3. Double-click to edit the text

## Editing Text

- **Double-click** the text element to enter edit mode
- Type your content
- Click outside or press **Escape** to finish editing

The text element automatically resizes to fit your content.

## Text Properties

### Font

| Property | Description |
|----------|-------------|
| Font Family | Choose from Google Fonts library |
| Font Size | Text size in pixels |
| Font Weight | Normal, bold, or other weights |
| Font Style | Normal or italic |

### Color

| Property | Description |
|----------|-------------|
| Text Color | The fill color of the text |
| Stroke Color | Outline color (optional) |
| Stroke Width | Outline thickness |

### Alignment

| Option | Description |
|--------|-------------|
| Left | Align text to the left |
| Center | Center the text |
| Right | Align text to the right |

### Position & Transform

| Property | Description |
|----------|-------------|
| X / Y | Position on canvas |
| Width / Height | Text box size |
| Rotation | Angle in degrees |
| Opacity | Transparency level |

## Available Fonts

The text element supports Google Fonts including:

- **Bangers** - Bold comic book style
- **Comic Neue** - Friendly comic sans alternative
- **Permanent Marker** - Hand-drawn marker style
- **Roboto** - Clean sans-serif
- **Arial** - Classic sans-serif
- And many more...

## Tips

- Use Bangers or Comic Neue for authentic comic styling
- Add a stroke to make text stand out against busy backgrounds
- Keep narration boxes consistent throughout your comic
- Use larger font sizes for emphasis and smaller for details
