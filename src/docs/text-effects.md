# Text Effects

Text effects create dramatic comic-style impacts like POW!, BAM!, BOOM!, and ZAP!

## Adding Text Effects

1. Click the **Text Effect** button (E) in the toolbar
2. A POW! effect appears at the center of the canvas
3. Customize the text and styling in the Properties panel

## Text Effect Properties

### Text

Change the effect text to any word or phrase. Classic options include:
- POW!
- BAM!
- BOOM!
- ZAP!
- CRASH!
- WHAM!

### Colors

Text effects support multiple stroke layers for maximum impact:

| Property | Description |
|----------|-------------|
| Fill Color | Main text color (default: yellow) |
| Stroke Color | Primary outline color (default: black) |
| Stroke Width | Primary outline thickness |
| Outer Stroke | Secondary outline color (default: red) |
| Outer Stroke Width | Secondary outline thickness |

### Effect Type

| Type | Description |
|------|-------------|
| None | Flat text with no distortion |
| Bend | Curved/arched text effect |
| Perspective | Skewed 3D-like effect |

### Bend Settings

When **Bend** effect is selected:

- **Bend Amount** - Controls curve intensity (-100 to 100)
  - Negative values: curve upward (smile)
  - Positive values: curve downward (frown)

### Perspective Settings

When **Perspective** effect is selected:

- **Skew X** - Horizontal skew angle (-45 to 45)
- **Skew Y** - Vertical skew angle (-45 to 45)

### Font

| Property | Description |
|----------|-------------|
| Font Family | Choose your font (Bangers recommended) |
| Font Size | Text size |
| Letter Spacing | Space between characters |
| Text Alignment | Left, center, or right |

### Position & Transform

| Property | Description |
|----------|-------------|
| X / Y | Position on canvas |
| Rotation | Angle in degrees |
| Opacity | Transparency level |

## Tips

- Use contrasting colors for fill and strokes (yellow/black/red is classic)
- The outer stroke adds depth - use a bright color like red or orange
- Bend effect works great for action words
- Rotate effects slightly for dynamic impact
- Position effects near the action they represent
