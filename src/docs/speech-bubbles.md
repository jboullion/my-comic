# Speech Bubbles

Speech bubbles bring your characters to life with dialog and thoughts.

## Adding Speech Bubbles

1. Click the **Speech Bubble** button (B) in the toolbar
2. A bubble appears at the center of the canvas
3. Double-click to edit the text inside

## Editing Text

- **Double-click** the bubble to enter edit mode
- Type your dialog
- Click outside or press **Escape** to finish editing

## Speech Bubble Properties

### Text

| Property | Description |
|----------|-------------|
| Font | Choose from available fonts |
| Size | Text size in pixels |
| Color | Text color |
| Alignment | Left, center, or right |

### Bubble Style

Choose between two bubble shapes:

- **Round** - Classic comic speech bubble with smooth edges
- **Cloud** - Thought bubble with bumpy, cloud-like edges

### Appearance

| Property | Description |
|----------|-------------|
| Fill Color | Background color of the bubble |
| Stroke Color | Border color |
| Stroke Width | Border thickness |
| Corner Radius | Roundness of corners (Round style only) |

### Corner Shape

For **Round** style bubbles, you can customize corner shapes:

- Round (default)
- Bevel
- Notch
- Scoop
- Squircle

### Position & Transform

| Property | Description |
|----------|-------------|
| X / Y | Position on canvas |
| Width / Height | Bubble size |
| Rotation | Angle in degrees |
| Opacity | Transparency level |

## Tips

- Keep dialog concise - comics work best with short, punchy text
- Position bubbles in reading order (left to right, top to bottom)
- Use Cloud style for thoughts, Round style for speech
- Match font style to your comic's tone
