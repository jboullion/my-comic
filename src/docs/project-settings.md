# Project Settings

Configure default settings that apply to your entire project.

## Accessing Project Settings

Click the **Settings** button (gear icon) in the project header to open the settings panel.

## Page Defaults

Set default dimensions for new pages:

| Setting | Description |
|---------|-------------|
| Width | Default page width in pixels |
| Height | Default page height in pixels |
| Background Color | Default page background |

### Preset Sizes

- **Standard Comic** - 800 x 1200 px (portrait)
- **Manga** - 600 x 900 px (portrait)
- **Square** - 1000 x 1000 px

## Text Defaults

Configure default styling for new text elements:

| Setting | Description |
|---------|-------------|
| Font Family | Default font |
| Font Size | Default text size |
| Text Color | Default text color |

## Speech Bubble Defaults

Configure default styling for new speech bubbles:

| Setting | Description |
|---------|-------------|
| Bubble Style | Round or Cloud |
| Fill Color | Default background color |
| Stroke Color | Default border color |
| Stroke Width | Default border thickness |
| Font Family | Default text font |
| Font Size | Default text size |
| Text Color | Default text color |

## Text Effect Defaults

Configure default styling for new text effects:

| Setting | Description |
|---------|-------------|
| Fill Color | Default main color |
| Stroke Color | Default primary outline |
| Stroke Width | Default outline thickness |
| Outer Stroke | Default secondary outline |
| Font Family | Default font |

## Saving Settings

- **Save** - Updates defaults for new elements only

## Tips

- Set up your preferred defaults before creating content
- Match your defaults to your comic's visual style for consistency
