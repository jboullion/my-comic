# Images

Images are the foundation of your comic. Import photos, illustrations, or AI-generated art to build your panels.

## Adding Images

### Upload Button
Click the **Image** icon in the toolbar and select files from your computer.

### Drag and Drop
Drop image files directly onto the canvas from your file explorer.

### From Assets
Drag an image from the **Assets** tab in the right sidebar onto the canvas.

## Image Properties

Select an image to see its properties in the right sidebar.

### Position & Size

| Property | Description |
|----------|-------------|
| X / Y | Position coordinates on the canvas |
| Width / Height | Image dimensions in pixels |
| Rotation | Angle in degrees (0-360) |
| Opacity | Transparency level (0-100%) |

### Border

- **Border Color** - Color of the image border
- **Border Width** - Thickness of the border in pixels

### Corner Shape

Transform your image corners with these options:

| Shape | Description |
|-------|-------------|
| Round | Standard rounded corners |
| Bevel | Angled/cut corners |
| Notch | Step-shaped corners |
| Scoop | Inward curved corners |
| Squircle | Smooth super-ellipse corners |

- **Corner Radius** - Controls how much the corners are modified (0-50%)

### Aspect Ratio

Enable **Lock Aspect Ratio** to maintain proportions when resizing. This prevents your images from becoming stretched or squashed.

## Tips

- Use high-resolution images for better export quality
- Organize frequently used images in the Assets panel
- Apply consistent border styles across panels for a cohesive look
