# Keyboard Shortcuts

Speed up your workflow with these keyboard shortcuts.

## General

| Action | Shortcut |
|--------|----------|
| Save | `Ctrl+S` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Shift+Z` or `Ctrl+Y` |

## Selection

| Action | Shortcut |
|--------|----------|
| Delete selection | `Delete` or `Backspace` |
| Toggle selection | `Ctrl+Click` |
| Add to selection | `Shift+Click` |

## Movement

| Action | Shortcut |
|--------|----------|
| Nudge 1px | Arrow keys |
| Nudge 10px | `Shift` + Arrow keys |

## Canvas Navigation

| Action | Shortcut |
|--------|----------|
| Pan canvas | `Space` + Drag |
| Zoom | Mouse wheel |
| Fast zoom | `Ctrl` + Mouse wheel |

## Tools

| Action | Shortcut |
|--------|----------|
| Select tool | `V` |
| Add text | `T` |
| Add speech bubble | `B` |
| Add text effect | `E` |

## Rotation

| Action | Shortcut |
|--------|----------|
| Snap to 15 degrees | `Shift` + Rotate |

## Tips

- **Mac users**: Replace `Ctrl` with `Cmd`
- Most shortcuts work when the canvas has focus
- Double-click text elements to edit inline
