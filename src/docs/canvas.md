# Canvas Navigation

Master the canvas controls to work efficiently on your comic pages.

## Zooming

### Mouse Wheel
- **Scroll up** - Zoom in
- **Scroll down** - Zoom out
- **Ctrl + Scroll** - Faster zoom

### Zoom Controls
Use the floating buttons at the bottom-center of the canvas:
- **+** - Zoom in
- **-** - Zoom out
- **Fit** - Auto-fit page to screen
- **Percentage** - Click to reset to 100%

## Panning

Move around the canvas when zoomed in:

### Middle Mouse Button
Click and drag with the middle mouse button to pan.

### Spacebar
Hold **Space** and drag to pan. Release Space to return to normal mode.

## Selecting Elements

### Single Selection
Click on any element to select it. Selected elements show blue handles.

### Multi-Selection

| Action | Result |
|--------|--------|
| Ctrl+Click | Toggle element in/out of selection |
| Shift+Click | Add element to current selection |

### Deselecting
Click on empty canvas space to deselect all elements.

### Selection Indicators

- **Primary selection** (first selected) - Shows resize and rotate handles
- **Secondary selections** (additional) - Shows dashed border outline

## Transforming Elements

### Moving

| Method | Description |
|--------|-------------|
| Drag | Click and drag any selected element |
| Multi-move | Dragging one moves all selected elements |
| Nudge | Arrow keys move by 1px |
| Fast nudge | Shift + Arrow keys move by 10px |

### Resizing
Drag the corner or edge handles to resize. Enable **Lock Aspect Ratio** in properties to maintain proportions.

### Rotating
Drag the circular handle above the element to rotate. Hold **Shift** while rotating to snap to 15-degree increments.

## Layer Order

Elements stack on top of each other. Control the order with the context menu (right-click):

| Action | Description |
|--------|-------------|
| Bring to Front | Move to the top |
| Bring Forward | Move up one layer |
| Send Backward | Move down one layer |
| Send to Back | Move to the bottom |

## Tips

- Use **Fit** zoom to see the entire page
- Hold **Shift** while rotating for precise 15-degree angles
- Enable **Snap to Grid** for aligned layouts
- Use arrow keys for pixel-perfect positioning
