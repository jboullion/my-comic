# Storage & Saving

## How Your Projects Are Stored

Comic Book Maker stores all your projects locally in your browser using **IndexedDB**, a built-in browser database. This means:

- **Private** - Your projects never leave your device
- **Persistent** - Projects remain available across browser sessions
- **No Account Required** - No sign-up or login needed

## Automatic Saving

Your work is saved automatically as you make changes. The save status indicator in the header shows:

- **Saving...** - Changes are being saved
- **Saved** - All changes have been saved

## Storage Limits

Browsers allocate storage space based on your available disk space. You can view your current storage usage in **Project Settings > Storage**. If storage runs low:

- Delete unused projects from the Projects page
- Export projects to files to back them up and free space

## Backing Up Your Work

Since projects are stored only in your browser, they can be lost if you:

- Clear your browser data or cache
- Uninstall and reinstall your browser
- Use a different browser or device

To protect your work:

1. **Export to File** - Use the export menu to save your project as a `.mycomic` file
2. **Open From File** - Use the "Open" button on the Projects page to restore a backed-up project

## Moving Projects Between Devices

To transfer a project to another device or browser:

1. Export the project to a `.mycomic` file
2. Transfer the file to the other device
3. Open the file from the Projects page
