# Features Documentation Update

Update all project documentation after completing a feature.

## Instructions

Read and follow the checklist in `.github/instructions/features-checklist.md`.

## Workflow

1. **Ask what feature was completed** if not provided in the command

2. **Update CLAUDE.md**
   - Add to "Current Features" list
   - Update "Important Files" table if new files created
   - Update phase number for major milestones

3. **Update relevant `src/docs/*.md` page(s)**
   - Match feature to appropriate documentation file
   - Add clear, user-friendly descriptions

4. **Update CHANGELOG.md**
   - Add entry under "Unreleased" section
   - Use categories: Added, Changed, Fixed, Removed

5. **Sync `.github/copilot-instructions.md`**
   - Keep feature list consistent with CLAUDE.md
